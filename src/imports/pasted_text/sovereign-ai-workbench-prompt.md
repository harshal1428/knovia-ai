# MASTER FIGMA AI PROMPT

## Sovereign AI Workbench — MRPL

Design a complete, production-ready enterprise web application called:

**Sovereign AI Workbench**

Subtitle:

**Private Intelligence for Confidential Industrial Work**

The application is designed specifically for **Mangalore Refinery and Petrochemicals Limited (MRPL)** and represents a sovereign, on-premise, air-gapped Agentic AI platform for confidential industrial work.

This is NOT a generic chatbot UI.

The interface must communicate:

* Sovereign / on-premise AI
* Confidential industrial knowledge
* MRPL workflows
* Agentic AI
* Adaptive model routing
* Hybrid RAG
* PostgreSQL / structured-data querying
* Multimodal AI
* Coding and isolated sandbox execution
* Engineering analysis and drawing generation
* Document intelligence
* Human approval
* RBAC
* Security and auditability
* Offline plugins
* Projects and collaboration
* Personal AI chat
* Knowledge/notebook workflows
* Notes and document research
* Local GPU infrastructure
* Multi-threading / multiprocessing / GPU scheduling
* Verified outputs and enterprise artifacts

The UI should feel like a **serious industrial intelligence operating system**, not ChatGPT, Notion, or a consumer AI application.
